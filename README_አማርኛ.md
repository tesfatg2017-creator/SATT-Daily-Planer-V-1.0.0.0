# SATT Planner — Android APK ፕሮጀክት (ስሪት 1.0 · 2019 ዓ.ም / 2026)

ይህ ፎልደር የAPK ምንጭ ነው። APK ራሱ እዚህ አልተሠራም — ከታች ካሉት መንገዶች በአንዱ ይሠራል።

## መንገድ 1 — GitHub (ኮምፒዩተር ላይ ምንም መጫን አያስፈልግም)
1. github.com ላይ አዲስ (private ሊሆን ይችላል) repository ክፈት።
2. ይህን ፎልደር ሁሉንም ፋይሎች (`.github` ፎልደርን ጨምሮ) upload አድርግ።
3. **Actions** ትር → "Build APK" → ሲጨርስ (~3-5 ደቂቃ) ከ **Artifacts** ውስጥ `SATT-Planner-v1.0-apk` አውርድ።
4. ዚፑን ፍታ → `SATT-Planner-v1.0.apk` ስልክህ ላይ ጫን ("ከማይታወቁ ምንጮች ጫን" ፍቀድ)።

## መንገድ 2 — Android Studio
